# URL → Markdown → LLM 전달 서비스

## 배경

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 추출해 보여주고, 복사·다운로드하거나
ChatGPT·Claude로 바로 넘길 수 있게 하는 도구. 회원가입 없이 세션 단위로 동작하는
학습 템플릿 규모의 유틸리티.

## 승인된 범위

- URL 입력 → 본문 Markdown 추출 (defuddle 라이브러리 사용, 필수 지정)
- 변환 결과 확인 (제목·저자 헤더 + 렌더링된 Markdown)
- 내보내기: 복사하기 / .md 다운로드 / ChatGPT·Claude로 열기
- 프롬프트 프리셋 3종 + 직접 입력(1회용)
- 다크모드 토글

## 사용자에게 보이는 동작 (수용 기준)

### 입력
- URL 붙여넣기 인풋과 지우기 버튼을 제공한다.
- 지우기 버튼은 입력값과 이미 표시된 변환 결과를 모두 초기화하고 입력 단계로 되돌린다.
- 빈 값이거나 URL 형식이 아니면 변환을 진행하지 않고 인라인 에러로 안내한다.

### 변환
- 서버가 대상 URL의 HTML을 가져와 defuddle로 본문을 추출한다.
- 추출에 실패하면(사이트 차단, 타임아웃, 본문 없음 등) 실패를 안내하고 입력 단계에서
  재시도할 수 있게 한다.

### 결과 확인
- 제목 헤더는 항상 표시한다.
- 저자는 추출된 경우에만 표시하고, 없으면 숨긴다.
- 추출된 Markdown을 렌더링된 형태로 보여준다.

### 내보내기
- **복사하기**: 변환된 Markdown 원문만 클립보드에 복사한다. 프롬프트는 포함하지 않는다.
- **.md 다운로드**: 변환된 Markdown만 파일로 저장한다. 프롬프트는 포함하지 않는다.
- **ChatGPT로 열기 / Claude로 열기**: 선택된 프롬프트(프리셋 또는 직접 입력, 선택하지
  않으면 프롬프트 없이 Markdown만)를 앞에 붙인 전체 텍스트를 클립보드에 복사하고, 각
  서비스의 새 채팅 페이지를 새 탭으로 연다. 사용자가 직접 붙여넣어(Cmd/Ctrl+V) 전송한다.
  ChatGPT·Claude 모두 동일하게 이 방식으로 동작한다.

### 프롬프트 선택
- 프리셋 3종: 요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘.
- 직접 입력: 프리셋 옆에서 선택하면 텍스트 인풋이 노출된다. 입력한 텍스트는 저장되지
  않고 현재 내보내기 동작에만 1회 사용되며, 페이지를 벗어나거나 새로고침하면 사라진다.
- 프롬프트를 선택하지 않아도 ChatGPT/Claude로 열기는 가능하다(Markdown만 전달).

### 다크모드
- 토글로 라이트/다크를 전환한다. 최초 진입 시 시스템 설정을 따르고, 사용자가 한 번
  전환하면 이후 방문에도 선택값을 기억한다.

## 정해진 제약과 근거

- **defuddle 라이브러리 사용은 필수** (사용자 지정 요구사항). 확인 결과(defuddle.md/docs,
  2026-08-19) defuddle는 브라우저·Node 양쪽에서 동작하며 DOM 또는 HTML 문자열을
  입력받아 정제된 콘텐츠와 title/author/description 등 메타데이터를 반환한다 — URL을
  직접 가져오지는 않으므로, 대상 URL의 HTML을 가져오는 책임은 이 서비스가 진다.
- **ChatGPT·Claude로 열기는 "클립보드 복사 + 새 탭 열기"로 통일한다** (사용자 확정).
  근거: Claude.ai는 URL로 채팅 내용을 미리 채우는 파라미터가 없고, ChatGPT의 `?q=`
  파라미터는 URL 길이 제한 때문에 기사 전체 분량의 Markdown에는 신뢰할 수 없다(확인:
  OpenAI 커뮤니티 포럼, 2026-08-19). 두 서비스의 동작을 동일하게 유지하기 위해 자동
  프리필을 포기하고 복사 기반으로 통일했다. 관련 근거는 향후 ChatGPT가 프리필 파라미터의
  길이 제한을 크게 늘리거나 Claude가 동등한 기능을 추가하면 재검토할 수 있다.

## 가정 (뒤집을 수 있음)

- 복사하기·.md 다운로드는 프롬프트를 포함하지 않고 순수 Markdown만 담는다. 프롬프트는
  "ChatGPT/Claude로 열기"에만 적용된다.
- .md 다운로드 파일명은 추출된 페이지 제목 기반으로 생성하고, 제목이 없으면 기본값을
  사용한다.
- 다크모드 설정은 브라우저에 저장되어 다음 방문에도 유지된다.

## 범위 밖

- 회원가입/로그인, 변환 이력 저장 — 사용자 흐름에 언급되지 않았고, 세션 단위 도구로
  범위를 한정한다.
- ChatGPT·Claude 외 다른 LLM 서비스 연동 — 사용자 흐름에 명시된 두 서비스만 지원한다.

## 유예된 사항 / 남은 리스크

- **클라이언트 렌더링(SPA) 사이트 지원 범위가 미확정이다.** 서버가 원본 HTML을 그대로
  가져오는 방식은 React/Vue 기반 SPA, 로그인벽이 있는 페이지 등에서 본문이 비어 있거나
  추출에 실패할 수 있다. 이 스펙은 우선 "서버사이드 HTML fetch만 지원, 실패 시 에러
  안내"로 진행하되, 헤드리스 브라우저 렌더링까지 지원할지는 사용자 확인이 보류된 상태다.
  구현 중 실제 실패율이 크면 재검토가 필요하다.
- defuddle의 출력이 Markdown을 직접 반환하는지, 아니면 정제된 HTML을 반환해 별도
  HTML→Markdown 변환이 필요한지는 문서 확인상 "정제된 HTML + 메타데이터"까지만
  확인했다. 정확한 변환 API는 구현 단계에서 추가로 확인이 필요하다.
