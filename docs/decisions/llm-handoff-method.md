# LLM Handoff Method

## Decisions

- 변환된 콘텐츠(+선택한 프롬프트)를 ChatGPT·Claude 같은 외부 LLM 채팅 서비스로 넘길 때는
  "클립보드에 복사 + 새 탭으로 서비스 열기" 방식을 쓴다. 사용자가 새 탭에서 직접
  붙여넣어(Cmd/Ctrl+V) 전송한다.

## Boundaries

- 이 방식은 대상 서비스가 URL 기반 프리필을 지원하지 않거나, 지원하더라도 넘길 콘텐츠가
  길어 URL 길이 제한을 넘을 수 있는 경우에 적용한다. 프리필 파라미터가 있고 넘길 내용이
  항상 짧다고 보장되는 별도 기능이라면 이 결정을 그대로 적용하지 않고 재검토한다.

## Why

- ChatGPT는 `?q=` URL 파라미터로 새 채팅에 텍스트를 미리 채울 수 있지만, 실제로는 URL
  길이 제한 때문에 짧은 문구에만 안정적으로 동작하고 기사 전체 분량의 Markdown에는 쓸 수
  없다.
- Claude.ai는 이런 프리필 파라미터 자체가 없다.
- 두 서비스의 동작을 동일하게 유지하기 위해 자동 프리필을 포기하고 복사 기반으로
  통일했다(서비스별로 다르게 동작하는 대안은 기각).

## Reconsider when

- ChatGPT가 프리필 파라미터의 길이 제한을 문서 분량까지 늘리거나, Claude.ai가 동등한
  URL 프리필 기능을 추가하는 경우.

## Still-rejected alternatives

- ChatGPT만 `?q=`로 자동 채우기 시도, Claude는 복사+새 탭 — 서비스마다 동작이 달라져
  사용자가 예측하기 어려움; 두 서비스가 동등한 프리필 기능을 지원하기 전까지는 재고하지
  않음.

## Evidence worth preserving

- ChatGPT `?q=` 파라미터 존재 및 길이 제한, Claude.ai에 프리필 파라미터가 없다는 점은
  OpenAI 커뮤니티 포럼 및 실사용 보고를 통해 확인함(2026-08-19 조사).
